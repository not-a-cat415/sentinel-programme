A new variant of chess: All piece chess

This is a new variant of chess where most pieces move the same. This is to make an easier game that anyone can understand.

There is no checkmate. Capturing the yellow token wins.

Blue tokens

Light blue tokens move up and dark blue circles move down. From a player's perspective, this is always up.

To capture, it moves diagonally up one space, but to move, it moves one space up.

Read about the piece this was inspired by (En passant has been removed)

Red tokens

Red tokens move an unlimited amount of squares in one of the 8 cardinal directions. It cannot go through other pieces.

Read about the piece this was inspired by

Yellow tokens

Yellow tokens move one space in one of the 8 cardinal directions. If it gets captured, the player whose yellow token was captured loses.

Read about the piece this was inspired by

Arrows

Arrows make it so that moving past the square with the arrow cannot be moving in the opposite direction of the arrow.

Green tokens (optional)

After playing a turn, the green token belonging to the player can be moved to any square on the board. It cannot be captured, and it blocks other pieces.

Special rules

If a blue token makes it to the other end of the board, it becomes a red token belonging to the same player.

If both sides only have a yellow token, the game is a draw unless one king can capture the other immediately.

If the same position occurs 4 times in a row, the game is a draw.
